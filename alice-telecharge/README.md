# Alice Telecharge

Simple Windows GUI for yt-dlp (Electron): queue, quality or MP3, local control API on 127.0.0.1 with a token.
Run Installer_AliceTelecharge.bat to download Electron, yt-dlp and ffmpeg on your PC.
Download only content you have the right to download.

Tested on Linux with a local server only. Not tested on Windows or on real sites by the author.
